## 报告漏洞

请使用 GitHub 仓库 **Security → Advisories → Report a vulnerability** 私下提交安全问题。不要在公开 Issue、讨论、日志或截图中发布 API Key、凭据、个人路径或复现所需的私人数据。

请提供受影响版本、影响范围、最小复现步骤和建议修复方式。维护者会先确认收到报告，再评估影响和发布修复版本。

JiMu-Harness 不会要求用户把本地 DeepSeek API Key 提交到仓库。GitHub Actions 的真实 API 测试使用独立、限额的仓库 Secret。

# Security Policy

## Supported versions

| Version | Security updates |
| --- | --- |
| `0.1.x` | Supported |
| Earlier versions | Unsupported |

## Reporting a vulnerability

Use **Security → Advisories → Report a vulnerability** in this repository to report security issues privately. Do not disclose API keys, credentials, personal paths, or private reproduction data in public issues, discussions, logs, or screenshots.

Include the affected version, impact, minimal reproduction steps, and any suggested remediation. The maintainers will acknowledge the report before assessing impact and preparing a fixed release.

JiMu-Harness never asks users to commit a local DeepSeek API key. Real-API GitHub Actions use a separate, limited repository secret.
